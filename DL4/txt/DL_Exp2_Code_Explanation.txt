DL EXPERIMENT 2 - FEEDFORWARD NEURAL NETWORK (KERAS + TENSORFLOW)
CODE BLOCK EXPLANATION
==================================================================

GOAL
----
Classify handwritten digits (0-9) from the MNIST dataset.
Each image is 28 x 28 pixels (grayscale).

FLOW
----
Load data -> View images -> Normalize -> Build model -> Compile
-> Train -> Evaluate -> Predict -> Plot graphs


==================================================================
CELL 0 : IMPORT LIBRARIES
==================================================================
Code:
    import tensorflow as tf
    from tensorflow import keras
    import pandas as pd
    import numpy as np
    import matplotlib.pyplot as plt
    import random
    %matplotlib inline

Explanation:
- tensorflow / keras : build and train the neural network
- pandas, numpy      : data handling and arrays
- matplotlib         : draw images and graphs
- random             : pick a random test image
- %matplotlib inline : show plots inside the notebook


==================================================================
CELL 1 : LOAD DATASET
==================================================================
Code:
    mnist = tf.keras.datasets.mnist
    (x_train, y_train), (x_test, y_test) = mnist.load_data()

Explanation:
- Loads the built-in MNIST dataset.
- Training set : 60,000 images (x_train) with labels (y_train)
- Test set     : 10,000 images (x_test) with labels (y_test)
- x = image pixels, y = actual digit (0-9)


==================================================================
CELL 2 : SHOW AN IMAGE
==================================================================
Code:
    plt.matshow(x_train[1])

Explanation:
- Displays the 2nd training image as a matrix plot.
- Used to check that the data loaded correctly.


==================================================================
CELL 3 : SHOW IMAGE IN GRAYSCALE
==================================================================
Code:
    plt.imshow(-x_train[0], cmap="gray")

Explanation:
- Displays the 1st training image in gray colors.
- The minus sign (-) inverts the colors (dark digit on light background).


==================================================================
CELL 4 : NORMALIZATION
==================================================================
Code:
    x_train = x_train / 255
    x_test = x_test / 255

Explanation:
- Pixel values are 0 to 255. Dividing by 255 makes them 0 to 1.
- Benefit: faster and more stable training.


==================================================================
CELL 5 : BUILD THE MODEL
==================================================================
Code:
    model = keras.Sequential([
        keras.layers.Flatten(input_shape=(28, 28)),
        keras.layers.Dense(128, activation="relu"),
        keras.layers.Dense(10, activation="softmax")
    ])
    model.summary()

Architecture:

    Input image      Flatten        Dense (ReLU)      Dense (Softmax)
     28 x 28    ->  784 values  ->  128 neurons   ->   10 neurons
                                                       (digits 0-9)
     0 params       0 params        100,480 params     1,290 params

Explanation:
- Sequential : layers are stacked one after another.
- Flatten    : converts the 2D image (28x28) into 1D (784 numbers).
- Dense(128, relu) : hidden layer with 128 neurons.
    ReLU keeps positive values and turns negative values to 0.
- Dense(10, softmax) : output layer, one neuron per digit.
    Softmax converts outputs into probabilities that sum to 1.
- model.summary() : prints layers, output shapes and parameter counts.

Parameter calculation:
- Hidden layer : 784 x 128 + 128 biases = 100,480
- Output layer : 128 x 10 + 10 biases   = 1,290
- Total                                  = 101,770


==================================================================
CELL 6 : COMPILE THE MODEL
==================================================================
Code:
    model.compile(optimizer="sgd",
                  loss="sparse_categorical_crossentropy",
                  metrics=['accuracy'])

Explanation:
- optimizer = sgd : Stochastic Gradient Descent. Updates weights
                    step by step to reduce the loss.
- loss = sparse_categorical_crossentropy : loss for multi-class
                    problems where labels are plain integers (0-9),
                    not one-hot encoded.
- metrics = accuracy : percentage of correct predictions.


==================================================================
CELL 7 : TRAIN THE MODEL
==================================================================
Code:
    history = model.fit(x_train, y_train,
                        validation_data=(x_test, y_test),
                        epochs=10)

Explanation:
- fit() trains the model.
- epochs = 10 : the model sees the full training data 10 times.
- validation_data : test data used to check performance after each epoch.
- history : stores loss and accuracy of every epoch (used for graphs).

Training loop:
    Images -> Model -> Prediction -> Compare with true label (loss)
       ^                                        |
       +------- Update weights (SGD) <----------+

Result: accuracy rises from about 84% (epoch 1) to about 95%.


==================================================================
CELL 8 : EVALUATE THE MODEL
==================================================================
Code:
    test_loss, test_acc = model.evaluate(x_test, y_test)
    print("Loss=%.3f" % test_loss)
    print("Accuracy=%.3f" % test_acc)

Explanation:
- Tests the trained model on the 10,000 test images.
- Output: Loss = 0.166, Accuracy = 0.952 (95.2%)


==================================================================
CELL 9 : SHOW A RANDOM TEST IMAGE
==================================================================
Code:
    n = random.randint(0, 9999)
    plt.imshow(x_test[n])
    plt.show()

Explanation:
- Picks a random index n from the test set and displays that image.
- n is reused in Cell 12 for prediction.


==================================================================
CELL 10 and 11 : VIEW ARRAYS
==================================================================
Code:
    x_train
    x_test

Explanation:
- Prints the normalized image arrays.
- Values are now between 0 and 1.


==================================================================
CELL 12 : PREDICTION
==================================================================
Code:
    predicted_value = model.predict(x_test)
    plt.imshow(x_test[n])
    plt.show()
    print(predicted_value[n])

Explanation:
- predict() gives 10 probabilities for every test image.
- predicted_value[n] shows the probabilities for image n.
- The predicted digit is the index with the highest probability.
    Example output: highest value 0.9737 at index 9 -> digit 9.
- To get the digit directly: np.argmax(predicted_value[n])


==================================================================
CELL 13 : ACCURACY GRAPH
==================================================================
Code:
    plt.plot(history.history['accuracy'])
    plt.plot(history.history['val_accuracy'])
    plt.title('model accuracy')
    plt.ylabel('accuracy')
    plt.xlabel('epoch')
    plt.legend(['Train', 'Validation'], loc='upper left')
    plt.show()

Explanation:
- Plots training accuracy and validation accuracy per epoch.
- Shows how well the model is learning.


==================================================================
CELL 14 : LOSS GRAPH
==================================================================
Code:
    plt.plot(history.history['loss'])
    plt.plot(history.history['val_loss'])
    plt.title('model loss')
    plt.ylabel('loss')
    plt.xlabel('epoch')
    plt.legend(['Train', 'Validation'], loc='upper left')
    plt.show()

Explanation:
- Plots training loss and validation loss per epoch.
- Both curves go down and stay close together, so there is
  no major overfitting.


==================================================================
KEY TERMS
==================================================================
Flatten      : 2D image -> 1D list of numbers
Dense        : every neuron connects to every neuron of next layer
ReLU         : max(0, x), adds non-linearity
Softmax      : converts outputs to probabilities (sum = 1)
SGD          : optimizer that updates weights to reduce loss
Epoch        : one full pass over the training data
Loss         : how wrong the predictions are
Accuracy     : % of correct predictions
Overfitting  : good on train data, poor on new data
